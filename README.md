🎬 Movie List Application

A simple and interactive Movie List Application built using HTML, CSS, and JavaScript.

🚀 Features

- Add new movies to the list.
- Display movies dynamically.
- Delete individual movies.
- Empty input validation.
- Simple and user-friendly interface.

🛠️ Technologies Used

- HTML – Structure of the application.
- CSS – Styling and layout.
- JavaScript – Functionality and DOM manipulation.

💻 What I Learned

- DOM Manipulation
- Event Listeners
- Functions and Conditions
- Creating and Removing HTML Elements
- JavaScript Interaction with HTML and CSS
